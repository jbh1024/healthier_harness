### 3. 앱 실행 및 UI 점검
- 상태: **완료** (2026-07-03)
- 환경: Docker MySQL + Spring Boot(dev) + Flutter 웹 릴리즈 빌드(정적 서빙) + headless Chromium(playwright-core, 시맨틱 트리 기반 구동)
- **웹 플랫폼 지원 추가**: `frontend/web/` 스캐폴딩 부재로 `flutter build web` 불가 → `flutter create . --platforms web` 실행
- 점검 플로우(모두 통과, 콘솔/HTTP 에러 0건):
  - 회원가입/로그인 → 학원 선택 → 홈(잔여 횟수, 빠른 메뉴)
  - 수업 목록/상세 → 수강 신청(자동 승인 APPROVED, 수동 승인 PENDING — DB 상태 확인)
  - 게시판 목록/상세(댓글 입력 UI), 공지 목록(중요 배지)/상세, 내 수강 목록
- **발견/수정 버그 2건**:
  1. `SecureStorageService.saveTokens()`가 `Future.wait` 동시 쓰기 → 웹(flutter_secure_storage_web)에서 암호화 키 생성 레이스로 토큰 복호화 실패(OperationError), 로그인 불가 → 순차 쓰기로 수정 + 복호화 실패 시 토큰 정리 복구(`_readOrRecover`) 추가
  2. 수업 상세에서 수강 신청 후에도 신청 버튼이 그대로 노출(중복 신청 가능) → `myEnrollmentsProvider` 연동해 신청 상태(PENDING/APPROVED/WAITLISTED)면 "신청 완료 — 상태" 배너로 대체
- 백엔드 관찰 사항: 필수 필드 누락 요청(예: 초대코드 생성 빈 바디) 시 400이 아닌 500 반환 — Jackson MismatchedInputException 예외 핸들러 미비 → **수정 완료** (`docs/백엔드500에러수정_20260703.md` 참고)
